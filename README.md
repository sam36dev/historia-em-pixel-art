# História em Pixel Art

Arquivos de publicação do canal **História em Pixel Art** (haisytech): os 66 livros da Bíblia, cada um em 12 minutos, em animação pixel art.

- `main` → `publicados.json`: lista dos episódios já enviados ao YouTube (a fábrica sempre publica o próximo que ainda não saiu, nunca pula).
- `publicar` → só o episódio da vez (`video.mp4`, `miniatura.png`, `dados.json`). Esse ramo é reescrito a cada episódio.
